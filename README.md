# Эхо-Бездна (Echo Abyss) — этап 1: механика звука

Мод для Fabric, Minecraft 26.2, Java 25.

## Что уже есть
- Любой шум превращается в расходящееся светящееся кольцо.
- Шум дают: шаги (малый радиус), бег (большой), ломание блоков (большой).
- Красться (Shift) — тишина. Шерсть или ковёр под ногами делает шаги тише на ступень.
- Враждебные мобы, до которых дошло кольцо, идут к источнику шума.
- Предмет-заготовка «Камертон колосса»: `/give @s echo_abyss:tuning_fork`.

Пока механика работает во всех измерениях, чтобы её можно было проверить где угодно.
Когда появится измерение, в `SoundWaves.java` нужно поставить `EVERYWHERE = false`.

## Как получить готовый мод через GitHub
1. Создай на github.com новый репозиторий (New repository), название любое.
2. Распакуй zip и загрузи ВСЁ содержимое в репозиторий (включая папку gradle и файлы gradlew, gradlew.bat): Add file -> Upload files.
   Проверь, что в репозитории есть папка `.github/workflows/` с файлом `build.yml`.
   Если её нет, создай вручную: Add file -> Create new file, в имени файла напиши `.github/workflows/build.yml` и вставь туда содержимое из архива.
3. Открой вкладку Actions. Сборка запустится сама (около 3-5 минут).
4. Когда она станет зелёной, открой её и внизу, в разделе Artifacts, скачай `echo-abyss-jar`. Внутри лежит `echo_abyss-0.1.0.jar`.
5. Положи этот jar в папку mods рядом с Fabric API 0.161.0+26.2 (или новее для 26.2).

Если сборка красная — открой её, скопируй текст ошибки и пришли мне.

## Как проверить в игре
Найди пещеру, встань за стеной от зомби и побеги: вокруг пойдут кольца, зомби подойдёт. Присядь или встань на шерсть — шум пропадёт.
